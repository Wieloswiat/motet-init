# Chip

Filters that toggle, and read-only notes and facts.

- `kind: 'filter'` is a toggle button (`aria-pressed`), selected shows a check and `accent-soft`.
- `kind: 'note'` is a content note with an info icon; `tone` `caution` or `danger` for stronger notes.
- `kind: 'fact'` states a fixed fact such as the lane ("In character").
- **Never** a coloured status dot inside a pill.
