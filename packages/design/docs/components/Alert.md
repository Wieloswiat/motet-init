# Alert

A message about this page or form that stays until its cause is gone.

- `Alert({ tone: 'info' | 'caution' | 'danger' | 'positive' | 'neutral', title, description, actions, onClose, variant: 'inline' | 'banner', live })`.
- A soft fill, an icon and a title. No coloured side stripe. Actions are outline or text buttons.
- Pass `live` only when the alert appears after the page has loaded.
