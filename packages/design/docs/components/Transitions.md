# Transitions

`Motet.transition(update, { types })`: every state change that moves things, as a view transition, and instantly under reduced motion. The preview filters a list (`filter`), swaps a pane (`forward`, `back`) and answers a roll request (`roll`).

- Name items with `.m-vt` and `--vt`; use `.m-vt-box` for a card or row whose shape changes, and `.m-vt-pane` for the region a directional change swaps.
- Names apply only while a transition runs, so they never change stacking or frosted surfaces at rest.
- See **Motion and view transitions** for the types, names and timing.
