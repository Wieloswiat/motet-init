# TextField

Labelled inputs, selects and textareas.

Labels sit above in `ui-label`. Help sits below, linked with `aria-describedby`, and only when it adds something the label doesn't. Errors use `danger-ink` with an error icon and name the problem in as few words as it takes ("Enter a name."). They don't reassure about anything else. Placeholders are examples, never labels. Multi-line fields use the reading face.
