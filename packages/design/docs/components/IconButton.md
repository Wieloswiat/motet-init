# IconButton

A compact action identified by an icon, always with an accessible name shown as its tooltip.

- Props: `icon`, `label` (required), `variant` (`standard`, `tonal`, `filled`), `size`, `pressed`, `expanded`, `count`.
- A `count` is a number in a bubble (99+ max), never a dot, and never pulses. Put the count in `label` too.
- `pressed` fills the icon and uses `accent-soft`.
